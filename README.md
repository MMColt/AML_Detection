Team CeeNN It Coming (pronounced Seen) is building a Computer Vision model to classify bone marrow slide images as AML positive. This work extends upon the foundation established by a [previous team](https://code.vt.edu/saina/marrowminded/-/tree/62de4a6ec6bf26e4167c43f80156b2dc23548955/) from last semester, whose segmentation and classification pipeline provided the starting point for our current model. Our team consists of Mason Colt, Sarayu Pulipati, Sarah Skaggs and is working alongside Drs. Angie Patterson (VT), Ifeyinwa Obiorah (UVA), Paul Waymack (Moleculin Biotech) and Mr. Fred Faltin (VT) to develop this model. In our project, we have equipped a combination of Omnipose, a python library specialized for cell recognition and segmentation, along with a custom trained RF-DETR Classifier from Roboflow to create a cell-counting algorithm that helps determine whether a certain image slide is indicative of AML.

"FINAL_PRODUCT" is the folder that contains the final scripts created by our team for the Spring 2026 Capstone class. Within this folder we also have instructions/dependencies to run the script, a tutorial video (which is also linked as a YouTube video [here](https://www.youtube.com/watch?v=A3ykaX-5TVk)), as well as some of our results (plots, reports) and test images. Additionally, in the omnipose_gui folder, we provide instructions to run the Omnipose Graphical User Interface (GUI) in the terminal to help with parameter tuning and visualization. For more information on the GUI, please read [here](https://omnipose.readthedocs.io/gui.html).
